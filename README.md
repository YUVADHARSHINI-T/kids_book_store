# Kids Book Store Website

## About the Project
Kids Book Store is a web-based project designed to provide a simple and user-friendly platform for browsing children's books. Users can explore available books, view prices, add books to a cart, and proceed through the shopping process.

The project demonstrates basic front-end web development and server-side programming using HTML, CSS, PHP, and MySQL.

## Features
- **Home Page:** Displays available children's books.
- **Book Details:** Shows book names, images, and prices.
- **Shopping Cart:** Allows users to manage selected books.
- **User Registration:** Provides a signup page for new users.
- **User Login:** Allows registered users to log in.
- **Checkout:** Provides a checkout process for placing orders.
- **Order Management:** Supports viewing and managing orders.
- **Contact Page:** Provides a form for user enquiries.
- **About and Help Pages:** Displays store information and assistance.

## Technologies Used
- **HTML** – Structures the web pages.
- **CSS** – Styles the website and improves its appearance.
- **PHP** – Handles server-side operations.
- **MySQL** – Stores user, book, cart, and order information.
- **XAMPP** – Provides the local Apache and MySQL development environment.

## How to Run the Project Locally

1. Install and open XAMPP.
2. Start the **Apache** and **MySQL** services.
3. Place the project folder inside the `htdocs` directory.
4. Create the required MySQL database and tables using phpMyAdmin.
5. Configure the database connection locally in `db.php`.
6. Open your browser and visit:

   `http://localhost/kids_book_store/`
